PR Quiz Demo is a two-in-one reference project. The first half is a fully functional Android app — a programming quotes reader built with Jetpack Compose, MVVM, Navigation3, manual dependency injection, and a caching data layer. The second half is a GitHub Actions workflow that automatically embeds a multiple-choice quiz into every pull request description, requiring reviewers to demonstrate genuine comprehension of the diff before the status check turns green. Together they form a practical template you can study, fork, and adapt: the app shows how modern Android pieces fit together, and the workflow shows how to make code review a learning exercise rather than a rubber-stamp.

## Project goals

PR Quiz Demo is deliberately a demo and reference project — not a production application. Every architectural decision (MVVM, manual DI via `AppContainer`, repository pattern, `StateFlow`-driven UI state) reflects patterns that are safe and straightforward to copy into real production apps. The code is intentionally free of third-party DI frameworks, complex abstractions, or generated code so that the architecture is easy to read and reason about. On the workflow side, the PR quiz turns the often-perfunctory code review step into something more engaging: reviewers must read the diff carefully enough to answer questions about it, and the author gets a richer conversation about the changes they made.

<Note>
  This project uses a `FakeQuoteApi` instead of a real network backend. The simulated network latency and random failures it introduces are **intentional** — they exist specifically to exercise the retry logic (up to 3 attempts with exponential backoff) and the in-memory caching layer in `CachingQuoteRepository`. Do not replace `FakeQuoteApi` with a no-op stub when exploring the project, as doing so will bypass the resilience patterns the architecture is designed to demonstrate.
</Note>
