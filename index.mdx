## How the PR Quiz works

<Steps>
  <Step title="A PR is opened">
    The GitHub Actions workflow triggers on `pull_request` events. It embeds a multiple-choice quiz into the PR description using a base64-encoded answer key hidden in HTML comments.
  </Step>
  <Step title="Reviewer ticks answers">
    The reviewer checks boxes in the PR description for each question. The workflow monitors edits and updates a commit status in real time.
  </Step>
  <Step title="Answers are graded">
    When all questions are answered, the bot grades them. A passing score sets a `success` commit status; wrong answers post explanations and set `failure`.
  </Step>
  <Step title="Comment-based fallback">
    Reviewers can also post `/answer 1A 2B 3C` as a comment to submit all answers at once without touching the description checkboxes.
  </Step>
</Steps>
